# Docs diet: one map, one reference, a short CLAUDE.md

- **Decision:** `docs/DESIGN.md` and the old `docs/SYSTEM.md` are one page, `docs/SYSTEM.md` (the pieces, one paragraph each). `docs/REFERENCE.md` describes only what exists, by topic, with no history; CLAUDE.md keeps the rules and a map and links to it; README says how to use it. INVENTORY.md, SESSION and `docs/reviews/` are deleted (git has them). Dead code is gone (`lab_pids`, `set_open_mode`, `ORANGE`, `project_path`); `known_path` is the one way to find a project's folder. `migrate_config` and `migrate_state` stay until they are a week old. Three decisions whose main claim was removed are superseded: beam-in-beam-out, loud-problems-red-only-when-rare, lab-digest-and-tools-copy-report.
- **Why:** the docs described removed features, repeated each other and disagreed; every agent read them and paid for them again on every turn.
- **Rejected:** keeping DESIGN.md as the long walk-through (it was the biggest source of drift).
